## Overview

This directory contains the scripts used to generate the figures presented in the paper. Each subdirectory is named after the corresponding figure number and includes all necessary scripts and data required to reproduce that figure.

A separate `README.md` file is provided within each `data/` subdirectory, describing how the associated datasets were generated or processed.

**Directory structure example**

```
Fig3/
├── fig3_b.ipynb            # Jupyter notebook for plotting Figure 3b
├── ...                     # Other plotting scripts
└── data/
    ├── ...                 # Data files used by the plotting scripts
    └── README.md           # Documentation describing data generation and processing
```
